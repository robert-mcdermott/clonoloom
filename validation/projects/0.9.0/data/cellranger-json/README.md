# Simulated Cell Ranger annotation evidence

Generated by `uv run --no-project testdata/make-cellranger-json.py`. No participant
data or vendor source code is included. Unequal reads/UMIs, repeated sample-scoped
barcodes, multiple chains, a background barcode, null calls, zero support and an
unresolved mixed-chain contig exercise import semantics.

The short coding constructs are illustrative, not full receptor transcripts. Planted
full-length/productivity flags are source assertions for reader tests, not validated
biological function. JSON, CSV and AIRR representations share the stated values;
legacy JSON deliberately omits sample/full-length fields. Exact numeric extensions
test evidence preservation rather than abundance. The independent reference is
`validation/reference/cellranger_json.py`; supported limits are in `docs/CELLRANGER-JSON.md`.
