Automation permissions

Give a program only the capabilities its workflow needs, and review its proposed project changes in the window.

ClonoLoom 0.8.0: API 2 changes remote control to read-only by default. MCP transport is available; Python is available; R is available.

Choose capabilities at startup

clonoloom --remote-control
clonoloom --remote-control --allow compute,files
clonoloom --remote-control --allow edits,compute,files,network

The action catalog declares conservative read, edit, computation, file and network effects. Calls need every declared capability; non-read calls also need the connection token. A token is not permission to edit. Offline mode still prevents downloads. These controls govern the automation interface, not the operating system or the window's ordinary local APIs.

Review a named proposal

The window shows who proposes the action, its arguments and its effects. Accept runs it once against the reviewed project state. Reject leaves it unexecuted. Changed projects and disconnected callers require a new proposal. There is no remote acceptance action.

Project edits use normal Undo and carry the caller's name in History. UI controls, downloaded files and completed worker outputs have different recovery limits. Cancel prevents later attachments; already completed side effects may remain, and the window stays busy until the call settles.

Inspect what happened

This in-memory audit is not a scientific certificate or a persistent forensic log. Save it before stopping if you need it. Scientific methods and parameters remain in native result manifests.

Query a declared population

query_clonotypes accepts bounded conjunctions, disjunctions, negation and declared numeric or literal text predicates. No SQL, shell, regular expressions or evaluated code. It uses the current definition and QC, preserves the full table frequency denominator, and returns the original native JSON text for precise decoding.

Multiple-chain predicates can match different chains. Empty definition fields are not evidence of missing sequencing data. Query selection does not establish clonal expansion, specificity, significance or independent subjects.

See the complete permission, cancellation, audit and query contract for bounds and examples. Existing certificate replay remains a separate exact worker check with its five-kind support matrix; an accepted action is not a replay verdict.
