--- title: Install layout: page heading: Install ClonoLoom description: Install ClonoLoom on macOS, Linux or Windows with one command. One self-contained program, checked against its SHA-256 checksum, with no administrator rights needed. lede: ClonoLoom is one executable. The browser application is inside it, so nothing else needs to be installed; example data are downloaded only when you ask. One command downloads the release for your computer, checks it and installs it. --- 
$ curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/robert-mcdermott/clonoloom/main/install.sh | sh

Installs the latest release as ~/.local/bin/clonoloom. No sudo, and your PATH is left as it is; if ~/.local/bin is not on it, the installer prints the full path to run.

PS> irm https://raw.githubusercontent.com/robert-mcdermott/clonoloom/main/install.ps1 | iex

Run in PowerShell. Installs to %LocalAppData%\Programs\ClonoLoom and adds it to your user PATH. No administrator rights and no change to the execution policy needed.

Start it

$ clonoloom

ClonoLoom starts a local server on http://127.0.0.1:8860 (or the next free port up to 8879) and opens its window. If Chrome, Edge, Brave or Chromium is installed, the window is a desktop app window with its own profile; otherwise your default browser is used. Closing the window stops the program. On Windows, open a new terminal after installing so that it sees the updated PATH.

Files and folders named on the command line (AIRR tables, Cell Ranger output folders, immunoSEQ exports, MiXCR clone tables, OAS and OTS units, tcrdist3 clone tables, or folders of them) open directly as one dataset, and running clonoloom <paths> again while it is open hands them to the open window:

$ clonoloom /path/to/airr_rearrangement.tsv

Then continue with Getting started.

The window is a page in a current browser; ClonoLoom is tested in Chrome and the browsers built on Chromium. Each release has SHA256SUMS, the checksum of every file; the installers require exactly one matching checksum and run the downloaded program's --version before moving it into place, so a failed download never replaces a working copy.

Memory follows the data: a million rearrangements take about 130 MB once read (58 bytes a row and their junctions), and a cohort's tables are kept in a cache on disk so that it reopens in a fraction of a second.

Options

To install a particular release, or somewhere else:

$ curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/robert-mcdermott/clonoloom/main/install.sh | CLONOLOOM_VERSION=v{{version}} CLONOLOOM_INSTALL_DIR="$HOME/bin" sh

In PowerShell, set $env:CLONOLOOM_VERSION and $env:CLONOLOOM_INSTALL_DIR before the same command. To read an installer before running it, download it first; INSTALLING.md describes every option, and how to install by hand.

The program's own options:

FlagDefaultWhat it does

--remote-controloffLet programs on this computer drive the window (remote control)

--versionPrint clonoloom X.Y.Z and exit

Upgrading and uninstalling

Run the installer again to upgrade; it replaces the program only after every check passes. On Windows, stop ClonoLoom first. To go back, install the release you want by its tag. Each release opens the projects earlier releases saved.

To uninstall, delete the program (~/.local/bin/clonoloom, or %LocalAppData%\Programs\ClonoLoom and its PATH entry). Your projects and the cache stay where they are (where things are kept) until you delete them.

Building from source

With Go (the version in go.mod or newer), and nothing else:

$ git clone https://github.com/robert-mcdermott/clonoloom.git
$ cd clonoloom
$ go build -o clonoloom .
