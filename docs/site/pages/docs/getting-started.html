Install and start it

Install ClonoLoom with the one-line installer (Install), then run:

$ clonoloom

ClonoLoom opens in its own window: Chrome, Edge, Brave or Chromium in app mode if you have one, else your default browser (--window browser asks for it). It runs on your computer only: nothing is uploaded, and it reaches no other computer unless you ask it to download example data (--offline stops even that). Closing the window stops ClonoLoom (--keep-running keeps it serving).

The start page of a first run: open data, an example or a saved project.

You can also name files on the command line: clonoloom run1/outs opens a Cell Ranger output folder, and running it again while ClonoLoom is open hands the files to the open window.

Every downloaded file is checked against the checksum recorded when ClonoLoom was released. Data under a provider's terms of use (the immuneACCESS data) need you to read and accept the terms first. Open T cells (or B cells) then opens an example as a dataset, which carries its license and citation from then on. The simulated studies are labeled simulated wherever they are shown; see Simulated studies.

To follow the guide, download Human PBMC from a healthy donor, 1k cells and open its T cells; for the Repertoire pages, open A simulated TRB study with known truth.

The window

The rail on the left holds the views, in the order an analysis goes: Data, QC, Clonotypes, Repertoire and Jobs, and the views later releases fill (each says what it will do). The project tree beside them lists the datasets and the results kept; the inspector on the right describes what is chosen; the status bar shows the library, the datasets and the clonotype definition in use. Search or run a command (⌘K or Ctrl+K) finds any command, and undo and redo cover every change. The theme button in the header chooses a light or dark theme (or the system's), and turns on color-vision-friendly colors.
