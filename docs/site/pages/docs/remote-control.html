--- title: Remote control description: Drive the open ClonoLoom window from a script or a notebook: open data, choose a clonotype definition, measure diversity, rarefaction, gene usage and overlap, and read the answers as JSON. lede: A program on your computer (a script, a notebook, the documentation's screenshot capture) can drive the open ClonoLoom window. Each action is performed in the window, where you see it, and what it changes goes into the project's history like any edit of yours, so it can be undone. ---

Turn it on

$ clonoloom --remote-control

ClonoLoom then writes remote.json to its library folder (where things are kept): its address and a token. The file is readable by you only, and removed when ClonoLoom stops. Keep a ClonoLoom window open: actions are performed by the window most recently opened.

Send an action

POST {"action": …, "args": {…}, "client": "what your program calls itself"} to /api/remote/action; the answer is {"ok": true|false, "message": …, "data": …}. In Python, with the standard library alone:

import json, pathlib, urllib.request

info = json.loads(pathlib.Path("~/Library/Application Support/ClonoLoom/remote.json").expanduser().read_text())

def act(action, **args):
    request = urllib.request.Request(info["url"] + "/api/remote/action",
        data=json.dumps({"action": action, "args": args, "client": "my notebook"}).encode(),
        headers={"Content-Type": "application/json", "X-ClonoLoom-Token": info["token"]})
    return json.load(urllib.request.urlopen(request))

act("open_example", example="simulated-standard")
act("annotate_samples", samples={"S01-1": {"timepoint": "day 0"}, "S01-2": {"timepoint": "day 0"}})  # replicates
diversity = act("measure_diversity")["data"]
print(act("show_methods")["data"]["text"])

Check a cohort design

check_cohort_design checks an explicit subject-level design. Send spec: {unit: "subject", layout: "independent", groupField: "condition", levels: ["control", "expanded"], exclude: {sample: "reason"}}, plus optional dataset, name and save: true. Use layout: "paired" for within-subject observations. The answer includes sample membership, subject counts, findings and citations; it performs no statistical test. See Cohort study design.

The actions

ActionWhat it does
get_stateThe project: its datasets (format, unit, rows, samples, findings, filter, definition, license and citation of public data), the view shown, the example datasets
new_projectStarts a new project
open_dataOpens files or folders as one dataset; another tool's table through a mapping of its columns (needs the token)
open_exampleOpens an example dataset, downloading openly licensed data first when asked
showShows a view, with a dataset in focus
set_definitionChooses a dataset's clonotype definition: a preset by name, or one stated in full
annotate_samplesSets samples' subject, time point, reference role, tissue, cell subset, condition, batch and HLA
describe_subjectsAnswers each subject's samples in time order, its reference samples and replicates, and the checks' findings
track_clonotypesFollows a reference sample's largest clonotypes, each sample's largest, a list, a test's calls or a class through each subject's time points, and answers each one's frequency with its interval
class_clonotypesClasses each clonotype of each subject across time points against a base, and answers each subject's clonotypes by class
attribute_samplesMeasures each sample against its subject's reference sample, and answers the shares with their intervals
test_expansionTests each clonotype between two time points of each subject (the beta-binomial test where replicates allow), and answers the fit and each subject's calls with their p-values
select_clonotypeChooses a clonotype by its rank in the table or its ID
measure_diversityMeasures each sample's diversity and answers the main measures with their intervals
rarefyRarefies and extrapolates each sample and answers each at a chosen level
gene_usageCounts genes, junction lengths and amino acids, and answers the most used genes and commonest lengths
measure_overlapMeasures every pair's overlap and answers the most overlapping pairs and the public clonotypes
show_examples, show_methods, set_theme, close_dialogsThe Example data dialog; a dataset's methods paragraph with its references; the theme; closing dialogs

Every action's arguments are in the remote control reference; GET /api/remote/tools lists them as JSON Schema.

What is allowed

  • Only programs on this computer: requests from other computers, and web pages that reach the loopback port under another name, are refused.
  • Reading files by path (open_data) needs the X-ClonoLoom-Token header with the token in remote.json, so another user of a shared computer cannot make your ClonoLoom read your files.
  • Data under a provider's terms of use (the immuneACCESS example) are never downloaded by a program: only you can accept their terms, in the window.
  • One action runs at a time, in the order they come.

Invariant-population annotation

flag_invariant takes species: "human" | "mouse", an optional dataset, and optionally population: "MAIT" | "iNKT" | "GEM". It records the species and shows Clonotypes, returning the first 20 rows plus complete sample totals, matched and evaluable abundance and shares. The published sequence rules do not establish phenotype or specificity.

B-cell sequence evidence

In wave 5, inspect_bcell_inputs opens B cells → Inputs, returning evidence counts and at most 50 rearrangement summaries under the active QC filter. Optional dataset chooses the dataset and select inspects a row on that page, numbered from 1. It does not infer a germline or measure mutation.
